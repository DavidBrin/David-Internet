# P300 Speller demo notes

Live demo: `/demos/p300` · manifest: `content/p300/site.ts` · stage: `src/demos/p300/`

## What's on the page

- **#speller**, the live speller sim: a 6x6 character matrix flashing rows and
  columns at the real cadence (100 ms on / 75 ms off, 12 flashes x 15
  repetitions), scrolling 8-channel synthetic EEG (the CNN2a electrode set),
  an ERP-averaging animation where the P300 rises out of the target-flash
  average as repetitions accumulate, and live letter decoding with row/column
  score bars. SNR slider shows repetitions-needed vs signal strength. A
  photosensitivity warning gates the flashing; reduced-motion mode swaps
  strobing for static highlights.
- **#classifier**: the 650 ms x N-channel window as the CNN's input, the
  five-layer 1D CNN architecture, and a 64-electrode head map (approximate
  10-20 layout) with every electrode subset the model family used: all 64,
  CNN2a's 8 prefixed, CNN2b's learned 8 (subjects A and B differ), and CNN2c's
  six lobes. First-layer spatial-filter maps are **illustrative** (seeded
  smooth random maps, labeled); no trained checkpoint was archived.
- **#results**: the committed notebook outputs (subject B): weighted window
  accuracy for CNN1/2a/2b/2c/3 and MCNN1-3, the speller's character accuracy
  climbing 37% -> 94% over 15 repetitions, and the actual 100-letter test
  sentence with mistakes highlighted.

## Honesty notes

- **The codebase is third-party**: the notebooks, README and all quoted results
  are the open-source `p300-speller` project by Manuel Carzaniga (Manucar) and
  Lorenzo Gualniera (Gualor), at github.com/Manucar/p300-speller, archived here
  as study material from David's time on Triton Neurotech's ML team. David's
  role was on the ML side of the team's speller work (not the UI); none of the
  quoted runs are his. This is stated on the page (story beat 6 + source footer).
- No BCI Competition III data ships: the live sim runs on synthetic EEG
  (seeded noise + alpha + a P300 template), clearly labeled.
- The sim's per-flash scorer is template matching, not the CNN (stated on the
  page); the letter-decoding logic downstream of the scores is the notebook's
  own, ported to TypeScript and fixture-tested against the Python original
  (`tests/p300-core.test.ts`, fixture generated by the prep script running the
  notebook functions verbatim).
- Results are subject B only; each notebook archives exactly one run, and all
  committed runs are subject B (CNN2c's is the occipital subset).
- Head-map electrode positions are approximate 10-20 layout; the montage order
  was verified against the repo's CNN2a index-to-name mapping.
- Built 2026-09-01 with AI coding tools, per-page disclosure in the story rail.

## Building

`pnpm sync-demos p300` needs `py -3.12` with numpy + Pillow. Compresses the
three README figures to WebP, writes `results.json` + `head.json`, extracts
notebook code cells into `demos/p300_src/` (the drawer never inlines .ipynb),
and regenerates `tests/fixtures/p300-decode.json`.
